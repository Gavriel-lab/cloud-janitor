# Cloud Janitor

Cloud Janitor is a convenience tool for automating operations in cloud computing environments. It is intended for tasks such as creating clusters, cleaning up accounts, running maintenance jobs, and recording the results of those operations.

The project is designed to help developers and system administrators turn repeatable operational procedures into reusable tasks that can run from the command line, a container, GitHub Actions, Gitpod, or a Java runtime.

## What Cloud Janitor helps with

- Resolving task intent into concrete cloud operations
- Applying safe defaults from configuration
- Filtering resources so only matching resources are affected
- Running tasks across accounts, regions, or cloud providers
- Redacting sensitive output and supporting dry runs
- Keeping logs and reports for later review
